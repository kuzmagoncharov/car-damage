# car-damage

Программа определяет по фото, повреждён автомобиль или нет.

Классы: `damaged` и `normal`. Модель — предобученная **MobileNetV3-Small**, дообученная на ваших снимках.

## Подготовка

```bash
python -m pip install -r requirements.txt
```

Исходные фото лежат здесь:

```
data/raw/damaged/
data/raw/normal/
```

## Этапы

**1. Разбить датасет на обучение, валидацию и тест**

```bash
python prepare_data.py
```

Получится `data/split/{train,val,test}/{damaged,normal}/` — примерно 70% / 15% / 15%.

**2. Обучить сеть и посчитать метрики**

```bash
python train.py
```

Скрипт сохранит лучшие веса в `models/best.pt` и отчёт в `reports/`:

- accuracy, precision, recall, F1
- матрица ошибок
- список неверно классифицированных тестовых фото

**3. Проверить новое фото**

Через окно с кнопками:

```bash
python app.py
```

Или дважды нажмите `start.bat`. Дальше можно:

- нажать на область фото или кнопку **Выбрать фото**;
- вставить снимок из буфера: **Ctrl+V**.

Программа сразу покажет вердикт, аварийность и целостность.

Через командную строку:

```bash
python predict.py путь/к/фото.jpg
```

Пример ответа:

```
Класс: damaged
Вероятность: 91%
```

## Замечания

Сейчас в датасете около 40 снимков. Этого хватает, чтобы собрать рабочий пайплайн, но качество будет нестабильным. Лучше добавить больше разнообразных фото: разные ракурсы, освещение и фон.
